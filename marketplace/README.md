# Marketplace Assets

This directory contains ready-to-post listings, templates, and demo materials for Fiverr and Upwork.

Files:
- fiverr_gigs.md
- upwork_profile.md
- upwork_project_catalog.md
- proposal_templates.md
- portfolio_pdf_outline.md
- portfolio_pdf_google_docs.md
- demo_script_60s.md
- assets/fiverr_gig_images.md
- assets/fiverr_gig_image_layout_spec.md
- assets/portfolio_visuals.md

Usage:
- Copy text directly into Fiverr and Upwork.
- Use the assets notes to build gig images and a short demo video.
- Keep language research-grade. Avoid profit claims or unattended live trading promises.
