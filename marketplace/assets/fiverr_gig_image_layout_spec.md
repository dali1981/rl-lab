# Fiverr Gig Image Layout Spec

Goal:
- Clean, research-grade visuals with strong hierarchy and minimal text.
- Avoid profit claims and "live bot" language.

Canvas
- Size: 1280x769 px
- Safe area: 60 px padding on all sides
- Format: PNG

Typography
- Primary: "Space Grotesk" (Bold/Medium)
- Secondary: "IBM Plex Sans" (Regular)
- All caps only for short labels

Color Palette (no purple bias)
- Ink: #0B0F14
- Slate: #2B3640
- Sand: #F3F0E7
- Accent: #D97706 (amber)
- Accent 2: #0EA5A0 (teal)

Layout Grid
- 12-column grid
- Headline spans 7-8 columns
- Subhead spans 6-7 columns
- Footer disclaimer spans full width, small text

Image Structure (repeatable)
1) Top-left: Headline (max 5 words)
2) Under headline: Subhead (max 7 words)
3) Right side: 1 large visual block (chart or abstract shape)
4) Bottom: Disclaimer strip (small text)

Visual Motifs
- Use a single chart line or minimal candlestick motif
- Add a subtle diagonal band or circle crop for depth
- Keep contrast high for mobile readability

Copy Limits
- Headline: 20-28 characters
- Subhead: 30-40 characters
- Disclaimer: "Research-grade only" or "No profit guarantees"

Example Layout Copy
- Headline: "RL Trading Experiments"
- Subhead: "SB3 + Hydra + MLflow"
- Disclaimer: "Research-grade only"

Export Checks
- Readable on mobile at 25% zoom
- No more than 3 text elements
- Strong contrast between text and background
