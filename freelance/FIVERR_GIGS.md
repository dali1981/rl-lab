### Category
Programming & Tech > Data > Data Processing

### Search Tags
`dollar bars`, `volume bars`, `trading data`, `data pipeline`, `crypto data`, `market microstructure`

### Gig Description

**Upgrade from time bars to information-driven sampling!**

Dollar volume bars create bars based on traded value, not fixed time intervals. This produces:

- More normally distributed returns
- Reduced autocorrelation
- Market-adaptive sampling (more bars during active periods)
- Better features for ML models

**What I'll build:**

**Bar Creation Pipeline**
- Dollar volume bar sampling
- Configurable threshold (e.g., $1M per bar for BTC)
- Handles tick-by-tick data
- Efficient processing with Polars

**Feature Engineering**
- SMA ratios (configurable periods)
- Volatility indicators
- Fractional differentiation
- Z-score normalization

**Data Quality**
- No look-ahead bias
- Proper train/test splitting
- Missing data handling
- Outlier detection

**Output Formats**
- Parquet files (efficient storage)
- Delta Lake tables (versioning)
- Direct DataFrame output

Based on methodology from "Advances in Financial Machine Learning" by Marcos Lopez de Prado.
